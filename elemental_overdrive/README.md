# Elemental Overdrive — Bedrock Add-On

Adds the four **Elemental Relics** as items for Minecraft Bedrock Edition:

| Item | Identifier | Texture |
|---|---|---|
| Fire Relic | `elemental_overdrive:fire_relic` | Red fiery spiked crystal |
| Water Relic | `elemental_overdrive:water_relic` | Deep blue ocean shard cluster |
| Earth Relic | `elemental_overdrive:earth_relic` | Brown quartz mountain gem |
| Air Relic | `elemental_overdrive:air_relic` | Mystic topaz floating prism |

All relics are unstackable, epic rarity, and render with an enchantment glint.

## Structure

- `resource_pack/` — item textures (128x128), texture atlas mapping, display names
- `behavior_pack/` — data-driven item definitions (format 1.21.0)

Both packs must be applied together; the behavior pack declares the resource
pack as a dependency.

## Installing

**Option A — .mcaddon:** zip the two pack folders and rename:

```sh
cd elemental_overdrive
zip -r elemental_overdrive.mcaddon resource_pack behavior_pack
```

Open the `.mcaddon` file and Minecraft will import both packs.

**Option B — manual:** copy `resource_pack/` into `com.mojang/resource_packs/`
and `behavior_pack/` into `com.mojang/behavior_packs/`, then enable both on
your world.

## Getting the items in game

```
/give @s elemental_overdrive:fire_relic
/give @s elemental_overdrive:water_relic
/give @s elemental_overdrive:earth_relic
/give @s elemental_overdrive:air_relic
```

(Requires cheats/experiments as appropriate for your version. The relics also
appear in the creative inventory under Items.)

## Source art

The textures are generated by the `*_crystal_icon.py` scripts in the repo
root — edit those and re-copy the 128px PNGs here to restyle the relics.
