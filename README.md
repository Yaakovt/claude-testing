# Tic-Tac-Toe Game

A command-line tic-tac-toe game where you can play against an AI opponent.

## Features

- Play against an intelligent computer opponent
- The computer uses the minimax algorithm for optimal play
- Choose whether to go first or second
- Clean command-line interface
- Play multiple games in a row

## How to Play

1. Run the game:
   ```bash
   python3 tic_tac_toe.py
   ```

2. Choose whether you want to go first (X) or second (O)

3. Enter your move by typing a number from 0-8 corresponding to the board position:
   ```
   0 | 1 | 2
   ---+---+---
   3 | 4 | 5
   ---+---+---
   6 | 7 | 8
   ```

4. Try to get three in a row (horizontally, vertically, or diagonally) before the computer does!

## Requirements

- Python 3.x

```
$ python3 tic_tac_toe.py
```
